# Reel Project

A full-stack food reel sharing application where users can scroll and watch food reels similar to short video platforms.

## Features

* User Authentication using JWT
* Secure Login & Signup System
* Food Reel Upload Functionality
* Cloudinary Integration for media storage
* Infinite Reel Scrolling Experience
* MongoDB Atlas Cluster Database
* REST API Integration
* Full Stack Architecture

## Tech Stack

### Frontend

* React.js
* Axios
* React Router

### Backend

* Node.js
* Express.js
* MongoDB Atlas
* JWT Authentication
* Cloudinary

## Installation

### Clone Repository

```bash
git clone https://github.com/p03-eng/Reel-project-.git

### Backend Setup

```bash
cd Backend
npm install
npm run dev
```

### Frontend Setup

```bash
cd Froentend
npm install
npm run dev
```

## Environment Variables

Create a `.env` file inside Backend folder and add:

```env
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```
